# ♻️ WasteWise – ML-Based Waste Classification & Trader Matching Platform

🚀 **Finalist (Top 30 out of 500+ teams)**  
🏁 **24-hour National Hackathon at MNIT Jaipur**

---

## 🧠 Project Overview

**WasteWise** is a machine learning–driven waste management platform that classifies waste using a custom-built **Convolutional Neural Network (CNN)** and connects users with nearby waste traders through GPS-based matching.

This project was built in a 24-hour hackathon at **MNIT Jaipur**, and was selected as a **Top 30 finalist out of 500+ teams** nationwide.

---

## 🎯 Key Features

- 🧪 **ML-Based Waste Classification:**  
  Trained a CNN using TensorFlow and OpenCV to automatically **differentiate between biodegradable and non-biodegradable waste**, achieving **85% test accuracy** through optimized data preprocessing, augmentation, and tuning.

- 📍 **GPS-Based Trader Matching System:**  
  Implemented a real-time location-based matching system that facilitated **100+ successful waste trading transactions** between users and local traders.

- 🔁 **Integrated Full-Stack Architecture:**  
  Built a full-stack solution with a React.js frontend, and Flask + Node.js backend for ML and API handling.

---

## 🔧 Technologies Used

- **Machine Learning:** Python, TensorFlow, OpenCV, Kaggle
- **Backend:** Flask (for ML APIs), Node.js, Express.js
- **Frontend:** React.js
- **Database:** MongoDB
- **Other:** GPS Integration, REST APIs
